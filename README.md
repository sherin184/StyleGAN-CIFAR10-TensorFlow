
## 📖 1. Introduction

This project is a compact, from-scratch implementation of a generative network inspired by NVIDIA's StyleGAN (Style Generative Adversarial Network) architecture. Written using TensorFlow and Keras, it scales down the giant, high-resolution original StyleGAN concepts into a lightweight, educational script.
Instead of traditional GANs that feed noise directly into the generator, this model passes random noise (z) through an 8-layer Multi-Layer Perceptron (MLP) to create an intermediate style space (w). 
This style vector then controls the generator's layers using custom Adaptive Instance Normalization (AdaIN) blocks and added noise for fine-grain textures, synthesizing 32x32 images.

## ⚙️Procedure

1. Preprocessing: Scales a 20,000-image subset of CIFAR-10 to [-1.0, 1.0] and loads them in optimized batches of 64.
2. Latent Mapping: A random noise vector z passes through an 8-layer MLP mapping network to generate an intermediate style vector w.
3. Style Synthesis: The generator discards standard noise inputs; it starts with a static, learned 4×4 constant tensor and upsamples it progressively to 32×32.
4. AdaIN & Noise: At each resolution tier, per-channel random noise is added for fine texturing, and the style vector w controls the features via Adaptive Instance Normalization (AdaIN).
5. Adversarial Training: Uses custom TensorFlow training steps (GradientTape) to optimize the model using the non-saturating logistic GAN loss.
6. Evaluation: Notebook plots cross-layer Style Mixing and smooth Latent Space Interpolation grids.

## 🏗️ Model Architecture

The model consists of two main components:
- **Mapping Network:** An 8-layer Multi-Layer Perceptron (MLP) transforms the input latent vector \(z\) into an intermediate style vector \(w\).
- **Generator Network:** Uses a learned constant input, progressive upsampling, Adaptive Instance Normalization (AdaIN), and noise injection to generate 32×32 images.
- **Discriminator Network:** Learns to distinguish real CIFAR-10 images from images generated by the generator.
- **Adversarial Training:** The generator and discriminator are trained together, allowing the generator to improve the quality of its generated images over time.

## 📊 Results and Visualization
- **Generated Images:** Displays synthetic 32×32 images produced by the trained generator.
- **Style Mixing:** Combines styles from different latent inputs across generator layers to explore changes in visual features.
- **Latent Space Interpolation:** Generates intermediate images between two latent vectors to demonstrate smooth transitions in the learned latent space.
- **Training Progress:** Training outputs and visualizations help observe how the generator's outputs evolve during training.

## 🧪 Experiments
1. **Image Generation:** Generates new images from randomly sampled latent vectors.
2. **Style Mixing:** Combines style information from different latent vectors to study the effect of layer-wise style control.
3. **Latent Interpolation:** Interpolates between latent vectors to examine how generated images change gradually.
4. **Training Evaluation:** Observes generated samples and training behavior to understand the learning process.

## 💡 Key Features

## ⚠️ Limitations

- The model generates images at a low resolution of 32×32 pixels.
- Training uses a subset of the CIFAR-10 dataset rather than the entire dataset.
- The model is a simplified educational implementation and does not reproduce the full original NVIDIA StyleGAN architecture.
- Image quality depends on training duration, model configuration, and the diversity of the training data.
- Generated images may contain visual artifacts or lack clearly recognizable objects.

## 🚀 Future Improvements

- Experiment with different batch sizes, learning rates, and training durations.
- Improve image quality and training stability.
- Extend the generator to support higher-resolution images.
- Compare generated outputs using quantitative evaluation metrics such as Fréchet Inception Distance (FID), where appropriate.

## 🎯 Conclusion

This project demonstrates the core concepts behind style-based generative adversarial networks through a compact TensorFlow and Keras implementation. By combining latent mapping, AdaIN, noise injection, and adversarial training, the model explores how style information can influence image generation.

The style mixing and latent interpolation experiments provide insights into latent representations and the control of generated visual features. Overall, this project serves as an educational introduction to StyleGAN-inspired image synthesis using the CIFAR-10 dataset.
